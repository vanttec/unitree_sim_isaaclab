# grasp_bridge

Bridge DDS para ejecutar agarres en **Unitree G1 + Inspire** (sim o robot real).

Documentación completa del fork: [../README_CUSTOM.md](../README_CUSTOM.md).

## Uso rápido

```bash
source grasp_bridge/setup_local_dds.sh
python -m grasp_bridge.dds_ping
python -m grasp_bridge.cli 3
```
